## Installation

Clone the project

```bash
  git clone https://github.com/drabiot/A-Maze-ing.git
```

Go to the project directory

```bash
  cd A-Maze-ing
```

Generate the environment

```bash
  make install
```

Launch the script

```bash
  make run
  make debug	# Run the script with debug option
```
